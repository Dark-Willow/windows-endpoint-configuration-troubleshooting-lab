# Scenario 04 — System File Checker Repaired Corrupt Files

## Issue

System File Checker reported that corrupt files were found and repaired.

## Environment

- Client: WIN10-CLIENT
- Tool: Administrator Command Prompt
- Command: sfc /scannow

## Symptoms

The scan completed and displayed the message that Windows Resource Protection found corrupt files and successfully repaired them.

## Cause

Some Windows system files were damaged or inconsistent.

## Resolution

System File Checker completed the scan and repaired the detected files.

## Skills Demonstrated

- Windows repair commands
- Administrator Command Prompt
- System File Checker
- Endpoint maintenance documentation
